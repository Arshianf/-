# ایمن‌ساز — پروژه اندروید

نسخه‌ی توسعه‌یافته‌ی نمونه‌ی بررسی فایل با رابط تیره و سبز نئونی.

## امکانات پیاده‌سازی‌شده
- انتخاب یک فایل با Android Storage Access Framework؛ بدون دسترسی گسترده به حافظه
- محاسبه‌ی SHA-256 در رشته‌ی پس‌زمینه تا رابط کاربری قفل نشود
- نمایش نام، اندازه، نوع پسوند و اثرانگشت فایل
- نمایش توضیح جداگانه برای فایل‌های APK
- عدم حذف، تغییر یا اجرای فایل انتخاب‌شده

## محدودیت امنیتی مهم
این برنامه هنوز آنتی‌ویروس کامل نیست: موتور ضدبدافزار، بانک امضا، تحلیل رفتاری،
اسکن بلادرنگ یا سرویس اعتبارسنجی آنلاین ندارد. SHA-256 فقط شناسه‌ی محتوای فایل است
و به‌تنهایی بدافزار بودن یا نبودن را مشخص نمی‌کند. برای ساخت محصول ضدبدافزار واقعی
باید منبع معتبر تشخیص، زیرساخت به‌روزرسانی امن، سیاست حفظ حریم خصوصی و آزمون‌های
امنیتی مستقل اضافه شوند. هیچ تضمینی درباره‌ی شناسایی همه‌ی تهدیدها داده نمی‌شود.

## ساخت APK
نیازمندی‌ها: Android Studio، JDK سازگار و Android SDK مطابق compileSdk 35.
1. پوشه‌ی پروژه را در Android Studio باز کنید.
2. Gradle Sync را اجرا کنید.
3. از مسیر Build > Build Bundle(s) / APK(s) > Build APK(s) خروجی بگیرید.
4. خروجی debug معمولاً در `app/build/outputs/apk/debug/app-debug.apk` است.

یا در محیطی که Gradle و Android SDK تنظیم شده‌اند:
`./build_apk.sh`

## درباره‌ی حجم ۴.۵ مگابایت
هنوز APK کامپایل نشده است، پس اندازه‌ی خروجی قابل تأیید نیست. حجم نهایی به نسخه‌ی
ابزار ساخت، منابع، معماری و تنظیمات بسته‌بندی بستگی دارد. عدد ۴.۵ MB هدف است،
نه ویژگی تأییدشده‌ی این سورس.
